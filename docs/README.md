## Como publicar o diagrama

1. Abra [app.diagrams.net](https://app.diagrams.net/).
2. **File → Open from → Device** e selecione `docs/diagrama/toggle-master-fase1.drawio`.
3. Ajuste região, tipos de instância e nomes se mudarem no console.
4. Publique ou exporte (**File → Export as → PNG** e **URL** do diagrams.net) e cole o link no relatório de entrega.

O PDF da fase pede o link público do diagrama, além do arquivo no repositório.
